pyhealth.datasets.KiTS23Dataset
===============================

KiTS23 kidney tumour CT dataset. The loader reads ``kits23.json`` into one
event per case with its CT and segmentation paths, the benign / malignant
label and the pathology record (histologic subtype, ISUP grade, TNM stage).
