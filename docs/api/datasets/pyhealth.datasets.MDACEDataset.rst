pyhealth.datasets.MDACEDataset
=======================================

MDACE (MIMIC Documents Annotated with Code Evidence): ICD code evidence spans on MIMIC-III notes. For more information see `here <https://github.com/3mcloud/MDACE>`_. Note text comes from MIMIC-III ``NOTEEVENTS``, which requires PhysioNet credentialing.
