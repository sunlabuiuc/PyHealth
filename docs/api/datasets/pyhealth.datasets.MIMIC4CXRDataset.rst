pyhealth.datasets.MIMIC4CXRDataset
==================================

Chest X-rays and labels from MIMIC-CXR-JPG, a credentialed-access dataset on `PhysioNet <https://physionet.org/content/mimic-cxr-jpg/2.1.0/>`_. To combine it with the hospital tables, use :doc:`pyhealth.datasets.MIMIC4Dataset`.
