pyhealth.datasets.ISIC2020Dataset
=================================

SIIM-ISIC 2020 melanoma dermoscopy dataset: 33,126 training images from 2,056
patients, labelled benign or malignant. Open download (CC BY-NC 4.0,
non-commercial). ``root`` holds the ground-truth CSVs and the unzipped
``train/`` image folder; the class docstring gives the download links.

Source: `ISIC 2020 Challenge <https://challenge2020.isic-archive.com/>`_
