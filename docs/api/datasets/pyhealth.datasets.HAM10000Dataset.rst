pyhealth.datasets.HAM10000Dataset
=================================

HAM10000 dermoscopy dataset as released for ISIC 2018 Task 3: 10,015
training images of 7,470 lesions in seven diagnostic classes, plus the
official validation and test sets. Open download (CC BY-NC 4.0,
non-commercial). ``root`` holds the unzipped ``ISIC2018_Task3_*`` folders and
the lesion groupings CSV; the class docstring gives the download links.

Source: `ISIC 2018 Challenge <https://challenge.isic-archive.com/data/#2018>`_
