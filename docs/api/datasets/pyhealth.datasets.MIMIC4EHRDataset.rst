pyhealth.datasets.MIMIC4EHRDataset
==================================

The MIMIC-IV hospital and ICU tables (``hosp/`` and ``icu/``), a credentialed-access dataset on `PhysioNet <https://physionet.org/content/mimiciv/>`_. The open `MIMIC-IV demo <https://physionet.org/content/mimic-iv-demo/2.2/>`_ has the same layout. To combine it with notes, X-rays or ED data, use :doc:`pyhealth.datasets.MIMIC4Dataset`.
