pyhealth.datasets.PTBXLDataset
===================================

PTB-XL, a large publicly available 12-lead ECG dataset with 21,799 records from
18,869 patients. Open access on PhysioNet:
`https://physionet.org/content/ptb-xl/1.0.3/ <https://physionet.org/content/ptb-xl/1.0.3/>`_.
