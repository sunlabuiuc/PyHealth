pyhealth.datasets.ISRUCDataset
===================================

The open ISRUC-Sleep EEG database (subgroup I), refer to `doc <https://sleeptight.isr.uc.pt/>`_ for more information. Pass ``download=True`` to fetch it automatically; extracting the archives needs the standalone 7-Zip binary ``7zzs`` on ``PATH`` (Linux and macOS) or ``patool`` (Windows).
