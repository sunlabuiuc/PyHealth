pyhealth.datasets.COVIDBLUESDataset
===================================

COVID-BLUES bluepoint lung ultrasound dataset. The loader reads pre-extracted
video frames (or decodes the videos with an optional decoder) and labels each
frame with the patient's COVID-19 PCR result.
