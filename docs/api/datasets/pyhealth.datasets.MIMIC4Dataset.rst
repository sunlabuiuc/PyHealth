pyhealth.datasets.MIMIC4Dataset
===================================

The Medical Information Mart for Intensive Care (MIMIC-IV) database and its modules (EHR, notes, MIMIC-CXR-JPG, ED), all credentialed-access datasets on `PhysioNet <https://physionet.org/content/mimiciv/>`_ (see `the MIMIC docs <https://mimic.mit.edu/>`_). The open `MIMIC-IV demo <https://physionet.org/content/mimic-iv-demo/2.2/>`_ (100 patients) works for ``ehr_root``. The class docstring below lists each source and the folder each ``*_root`` should point to. To load a single module, see :doc:`pyhealth.datasets.MIMIC4EHRDataset`, :doc:`pyhealth.datasets.MIMIC4NoteDataset`, :doc:`pyhealth.datasets.MIMIC4CXRDataset` and :doc:`pyhealth.datasets.MIMIC4EDDataset`.
