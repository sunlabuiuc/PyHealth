pyhealth.datasets.MIMIC4EDDataset
=================================

`MIMIC-IV-ED <https://physionet.org/content/mimic-iv-ed/>`_, the emergency
department module of MIMIC-IV: ED stays, triage, vital signs, medication
reconciliation, Pyxis dispensing and ED diagnoses. To combine it with the
hospital tables, pass ``ed_root`` and ``ed_tables`` to
:class:`~pyhealth.datasets.MIMIC4Dataset`. The open `MIMIC-IV-ED demo
<https://physionet.org/content/mimic-iv-ed-demo/>`_ has the same layout.
