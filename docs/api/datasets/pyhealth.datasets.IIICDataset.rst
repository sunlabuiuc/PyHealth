pyhealth.datasets.IIICDataset
===================================

Dataset is available via the Brain Data Science Platform (BDSP): https://github.com/bdsp-core/IIIC-SPaRCNet

The IIIC Seizure dataset (SPaRCNet corpus) is a large collection of 10-second, 16-channel longitudinal bipolar (TCP) montage EEG segments annotated for seizures and rhythmic and periodic patterns along the ictal-interictal-injury continuum (Other, SZ, LPD, GPD, LRDA, GRDA).
