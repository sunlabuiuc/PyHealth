pyhealth.datasets.ISIC2019Dataset
=================================

ISIC 2019 dermoscopy dataset: 25,331 training images in eight diagnostic
classes from the HAM10000, BCN_20000 and MSK collections, plus the public
8,238-image test set. Open download (CC BY-NC 4.0, non-commercial). It
contains all of HAM10000 / ISIC 2018 Task 3, flagged per image. ``root``
holds the ISIC 2019 CSVs and unzipped image folders; the class docstring
gives the download links.

Source: `ISIC 2019 Challenge <https://challenge.isic-archive.com/data/#2019>`_
