pyhealth.models.sensor_transfer
===============================

Adaptive transfer learning from source sensors to a target sensor: IPD-weighted
pretraining on the source sensors one after another, then fine-tuning on the
target sensor, as in Zhang et al. (2024). The weighting can be switched to equal
or inverse weights, or turned off, to run a weighting ablation.
