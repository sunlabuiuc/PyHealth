pyhealth.tasks.FraminghamCompetingRiskPrediction
================================================

Creates one continuous-time competing-risk sample per Framingham participant.
The task returns a standardized 18-element feature vector, positive duration,
and cause label. It supports days or years and optional administrative
censoring for horizon ablations.
