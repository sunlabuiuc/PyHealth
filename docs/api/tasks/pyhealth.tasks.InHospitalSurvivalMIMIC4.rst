pyhealth.tasks.InHospitalSurvivalMIMIC4
=======================================

Time to in-hospital death after the first 36 ICU hours on MIMIC-IV, the
survival setting of TrajSurv (Zeng et al., MLHC 2025). Pairs with
:class:`~pyhealth.models.TrajSurv` (the ``dynamic`` series) and
:class:`~pyhealth.models.SurvivalMDN` (the flat ``summary`` vector).
