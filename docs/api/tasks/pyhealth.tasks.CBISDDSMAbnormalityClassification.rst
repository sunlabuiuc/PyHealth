pyhealth.tasks.CBISDDSMAbnormalityClassification
================================================

Image-level abnormality type on CBIS-DDSM: mass (1) vs calcification (0),
from the mass and calcification case-description CSVs. Images with lesions of
both types in one official split are skipped. Example:
``examples/mammo/cbis_ddsm_abnormality_resnet18.py``.
