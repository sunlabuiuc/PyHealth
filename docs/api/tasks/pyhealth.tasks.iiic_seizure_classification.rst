pyhealth.tasks.iiic_seizure_classification
==========================================

The ``iiic_seizure_classification`` module contains the multi-class EEG classification task for the IIIC Seizure (SPaRCNet) dataset.

``IIICSeizureClassification`` is an alias of
:class:`~pyhealth.tasks.iiic_seizure_classification.EEGSeizureIIIC`; both
names are exported from ``pyhealth.tasks``.
