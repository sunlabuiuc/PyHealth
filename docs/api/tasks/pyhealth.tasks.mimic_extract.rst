pyhealth.tasks.mimic_extract
============================

Binary ICU prediction tasks on MIMIC-Extract, reproducing the evaluation
tasks of CaliForest (Park & Ho, CHIL 2020): in-hospital mortality, in-ICU
mortality, and ICU length of stay greater than 3 or 7 days.
