pyhealth.tasks.BCIIV2aLeftRightImagery
======================================

Binary left-hand vs right-hand motor imagery for BCI Competition IV dataset
2a: the left/right subset of the four-class task (feet and tongue trials are
skipped), a common reduced benchmark on this dataset. Same epoch window,
artifact handling and official session split as
:class:`~pyhealth.tasks.BCIIV2aMotorImageryClassification`. See
``examples/eeg/bciiv2a/bciiv2a_left_right_imagery_sparcnet.py``.
