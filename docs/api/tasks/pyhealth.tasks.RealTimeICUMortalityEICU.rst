pyhealth.tasks.RealTimeICUMortalityEICU
=======================================

eICU-CRD version of :class:`pyhealth.tasks.RealTimeICUMortalityMIMIC4`
(laboratory features only) with the same sample format and feature ids, for
external validation of models trained on MIMIC-IV, as in Frost, Li & Harris,
`Robust Real-Time Mortality Prediction in the Intensive Care Unit using
Temporal Difference Learning <https://proceedings.mlr.press/v259/frost25a.html>`_
(ML4H 2024).
