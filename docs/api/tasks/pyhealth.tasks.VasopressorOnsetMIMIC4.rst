pyhealth.tasks.VasopressorOnsetMIMIC4
======================================

Vasopressor-onset prediction task on MIMIC-IV (after Wu et al. 2022). Same
cohort rules and inputs as :class:`pyhealth.tasks.VasopressorOnsetMIMIC3`;
the MIMIC-IV item ids and the mapping of age, admission type and care unit
are this port's own choices and are listed on the class.
