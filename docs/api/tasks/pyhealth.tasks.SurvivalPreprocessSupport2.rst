pyhealth.tasks.SurvivalPreprocessSupport2
=========================================

Survival probability preprocessing on :class:`~pyhealth.datasets.Support2Dataset`:
one sample per patient with demographic, disease, vital, lab, score and
comorbidity features, labeled with the 2-month or 6-month ground-truth survival
probability (``surv2m`` / ``surv6m``) as a regression target.
