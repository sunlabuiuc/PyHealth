pyhealth.tasks.CMMDSubtypeClassification
========================================

Molecular subtype (Luminal A, Luminal B, HER2-enriched, triple negative) of
malignant CMMD mammograms from the D2 cohort, taken from the clinical row of
the image's own breast. Example: ``examples/mammo/cmmd_subtype_resnet18.py``.
