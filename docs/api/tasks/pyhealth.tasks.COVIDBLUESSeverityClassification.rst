pyhealth.tasks.COVIDBLUESSeverityClassification
===============================================

Frame-level lung ultrasound severity scoring on COVID-BLUES: each frame gets
its video's expert severity score (0-3, Soldati et al. 2020) from
``severity.csv`` as a four-class label.
