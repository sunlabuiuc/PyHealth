pyhealth.tasks.ISIC2019Classification
=====================================

Multiclass diagnosis of ISIC 2019 dermoscopy images, with the official eight
classes or CLIMB's five, one sample per image, grouped by lesion, optionally
without the images shared with HAM10000.
