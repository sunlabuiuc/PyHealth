pyhealth.tasks.PTBXLBinaryClassification
========================================

Binary detection of one diagnostic superclass (MI, HYP, STTC, CD or NORM) on
PTB-XL 12-lead ECGs, resampled to 250 Hz as in
`Raghu et al., CHIL 2022 <https://proceedings.mlr.press/v174/raghu22a.html>`_.
