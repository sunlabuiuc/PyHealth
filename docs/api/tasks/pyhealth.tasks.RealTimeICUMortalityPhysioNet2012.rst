pyhealth.tasks.RealTimeICUMortalityPhysioNet2012
================================================

Open-access version of :class:`pyhealth.tasks.RealTimeICUMortalityMIMIC4` on the
PhysioNet/CinC Challenge 2012 data (no credentials needed): the same sample
format, the MIMIC-IV lab feature ids (plus vital signs), and 1/3/7/14/28-day
mortality labels from the challenge's survival times. Supports the
temporal-difference framework of Frost, Li & Harris,
`Robust Real-Time Mortality Prediction in the Intensive Care Unit using
Temporal Difference Learning <https://proceedings.mlr.press/v259/frost25a.html>`_
(ML4H 2024).
