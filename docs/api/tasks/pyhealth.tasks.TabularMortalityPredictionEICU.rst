pyhealth.tasks.TabularMortalityPredictionEICU
=============================================

ICU mortality on :class:`~pyhealth.datasets.eICUDataset` from one fixed-width
row of early features per ICU stay: age, sex, and the first and last value of
each laboratory test in an early window of the stay. This is the tabular
cohort that Lin, Yu and Lee (CHIL 2025) use to evaluate synthetic medical
records generated by LLMs, so real and synthetic rows can be scored with the
same PyHealth models.

Examples: ``examples/eicu_tabular_mortality_prediction_xgboost.py`` compares
early windows and feature sets with
:class:`~pyhealth.models.XGBoostModel` and scores synthetic training data;
``examples/eicu_tabular_mortality_llm_generation.py`` generates the synthetic
rows.
