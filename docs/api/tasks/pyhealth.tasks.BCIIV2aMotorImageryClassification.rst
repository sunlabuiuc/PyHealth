pyhealth.tasks.BCIIV2aMotorImageryClassification
================================================

Four-class motor imagery classification for BCI Competition IV dataset 2a,
one EEG epoch per trial (default [2, 6) s after trial start, the cue-to-end
imagery period), with the official session split stored on each sample.
