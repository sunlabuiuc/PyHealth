pyhealth.tasks.LNDbFindingClassification
========================================

Classification of LNDb CT findings from a patch centred on each finding:
non-nodule, nodule < 3 mm or nodule >= 3 mm, or the binary nodule >= 3 mm
question. Patches are 3D cubes or 2.5D orthogonal planes.
