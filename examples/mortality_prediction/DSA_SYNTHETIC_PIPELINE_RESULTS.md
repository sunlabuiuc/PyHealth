# DSA Synthetic Full-Pipeline Validation

## Setup
- Data: 12 synthetic ICU patients
- Split: 8 train / 2 validation / 2 test patients
- Hourly samples: 204 / 51 / 51
- Task: DecompensationMIMIC3
- Model: DSA (GRU, hidden dimension 16)
- Training: 1 epoch, CPU
- Evaluation metric: Test AuPRC

## Results

| Configuration | Synthetic Test AuPRC |
|---|---:|
| Truncated | 0.4706 |
| Truncated + Bias | 0.4659 |
| Truncated + Bias + survTLS | 0.5173 |

## Validation
- All three variants completed training and evaluation.
- Hourly samples and survival labels were generated by the
  DecompensationMIMIC3 task.
- Patient-level train/validation/test separation was used.
- The DSA model was trained through PyHealth Trainer.

## Limitations
- These are synthetic demonstration results, not MIMIC-III results.
- The synthetic test cohort is small.
- No statistical significance is claimed.
- This example does not independently demonstrate a new
  PyHealth Dataset contribution.
